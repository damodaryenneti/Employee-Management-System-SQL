# Employee Management System using SQL

## Project Overview
The Employee Management System is a MySQL-based database project designed to manage employee information, job departments, salaries, qualifications, leaves, and payroll.

## Business Problem
Managing employee information across separate records can cause data duplication, inconsistencies, and difficulties in tracking salaries and leave records. This project provides a centralized relational database to organize employee-related information efficiently.

## Objectives
- Centralize employee and department information.
- Establish relationships between tables using primary and foreign keys.
- Manage salary, bonus, qualification, leave, and payroll records.
- Analyze employee data using SQL queries.
- Generate useful insights to support HR and payroll decisions.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
1. Employee
2. JobDepartment
3. SalaryBonus
4. Qualification
5. Leaves
6. Payroll

## SQL Concepts Used
- CREATE TABLE and INSERT
- Primary keys and foreign keys
- Joins
- Aggregate functions
- Subqueries and derived tables
- Common Table Expressions (CTEs)
- Views
- Window functions

## How to Run the Project
1. Install MySQL Server and MySQL Workbench.
2. Download or clone this repository.
3. Open the SQL script in MySQL Workbench.
4. Execute the database creation and table scripts.
5. Insert the sample data and run the analysis queries.
